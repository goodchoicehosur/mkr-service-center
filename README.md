# MKR Service Center (MERN)

## Run
1. Install Node 18+ and MongoDB (or use a free MongoDB Atlas URI).
2. Backend:  cd server && cp .env.example .env  (edit values) && npm install && npm run dev
3. Frontend: cd client && npm install && npm run dev
4. Open http://localhost:5173  – staff panel at http://localhost:5173/#admin

Edit business name, phone, hours in client/src/App.jsx (BIZ constant).
